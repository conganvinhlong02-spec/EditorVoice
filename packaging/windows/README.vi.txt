EDITORVOICE - BẢN WINDOWS PORTABLE
==========================================

Cách mở
-------
1. Giải nén toàn bộ file ZIP vào một thư mục.
2. Nhấp đúp "EditorVoice.exe".
3. Chờ cửa sổ ứng dụng xuất hiện. Lần đầu model có thể cần tải về máy.

Lưu ý
-----
- Không chạy trực tiếp file EXE khi vẫn còn nằm bên trong file ZIP.
- Không tách file EXE khỏi hai thư mục "app" và "runtime".
- Ứng dụng cần Microsoft Edge (có sẵn trên Windows 10/11).
- Giọng clone, lịch sử và cấu hình trình duyệt được giữ tại:
  %LOCALAPPDATA%\EditorVoice
- Muốn gỡ ứng dụng: xóa thư mục đã giải nén.
- Muốn xóa toàn bộ dữ liệu cá nhân: xóa thêm thư mục AppData nêu trên.

Khắc phục lỗi
-------------
Nhật ký lần chạy gần nhất nằm tại:
%LOCALAPPDATA%\EditorVoice\logs\latest.log

Công nghệ giọng nói trong ứng dụng được phát hành theo giấy phép Apache-2.0.

Phiên bản quà tặng
------------------
Gói được build với tùy chọn `-Unlimited` không kiểm tra ngày hết hạn. Tùy chọn
này chỉ ảnh hưởng launcher của bản quà tặng; bản phát hành chuẩn vẫn giữ chính
sách thời hạn hiện tại.
